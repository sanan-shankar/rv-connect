front runner has to be. It sits beside [`brief.md`](brief.md), which is still the source of truth
for what Catch-ups is FOR. Where this file and `directions.md` disagree, this file wins: it is
later and it is him.

**What was cleaned, and what was not.** The same treatment `brief.md` documents. Fillers ("um",
"uh", "like" as a tic, "you know") are removed; stutters and restarts are merged. Where a word is
a suspected mis-hearing the transcribed word stays and the guess sits beside it in square brackets.
Everything else is his: same content, same order, every hedge, every reversal, every swear word,
because the register is part of the instruction. Paragraph numbers in **[Rn]** are the only
structural addition.
