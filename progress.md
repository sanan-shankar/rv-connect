# Progress Log

**The index, not the log.** One line per session, newest first; the full entry lives in that
month's file under `docs/history/`. That way this file stays readable and a session's own
write is one line rather than forty.

The rule before 2026-09-07 was the other way round — the full entry lived here and a closed
month was supposed to move out. Nothing enforced it, August closed and never moved, and this
file reached 11,604 lines and the fourth-largest in the repository. The owner chose the
inversion (2026-09-07, campaign question 20). `scripts/qa/progress-log.test.mjs` now fails the
build if an entry's body is written here instead of in its month file.

**Writing an entry:** append the full entry to `docs/history/progress-<YYYY-MM>.md` (create it
if the month is new), and add one line here, at the top of that month's list.
